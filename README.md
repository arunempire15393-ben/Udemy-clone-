
Udemy Clone

A simple Udemy website clone created as a  front-end project.

🎯 Objective

The goal of this project is to recreate the basic layout and design of the Udemy website using HTML and CSS.

🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox 

📌 Features

- Navigation bar with logo and search bar
- Udemy-style menu bar
- Recommended courses section
- Recommended topics section
- Popular courses section
- Course images, ratings, and details


📂 Project Goal

This project demonstrates basic front-end development skills, including:

- Creating semantic HTML structure
- Designing layouts with CSS
- Making websites responsive
- Creating reusable course sections
